## 🔐 Important Security Rule

Do not commit real `.env` files, MongoDB credentials, or JWT secrets.
Use `.env.example` files and set real values only in deployment environments.

---

## 🚀 Local Setup

### Backend
```bash
cd backend
copy .env.example .env
npm install
npm start
```

### Frontend
```bash
cd frontend
copy .env.example .env
npm install
npm run dev
```

---

## 🌐 Deployment Order

1. Push code to GitHub
2. Deploy backend to Vercel
3. Deploy frontend to Netlify
4. Set environment variables in hosting dashboards
